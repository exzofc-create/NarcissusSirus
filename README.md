# NarcissusSirus
Полноэкранное окно персонажа для WoW 3.3.5a на сервере Sirus. Модель в полный рост, снаряжение по дуге с уровнем предметов, метками чар и самоцветов. Вкладки: характеристики с подсветкой приоритетных под спек и комплект, таланты и символы, профессии, титулы, наборы одежды. Русский и английский язык, автоподбор масштаба.
