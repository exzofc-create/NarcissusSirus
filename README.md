# NarcissusSirus

Полноэкранное окно персонажа для World of Warcraft 3.3.5a на сервере **Sirus**.

Заменяет штатный лист персонажа: модель в полный рост на затемнённом игровом мире, снаряжение по дуге с названиями предметов, метками чар и разъёмов, а справа — вкладки с характеристиками, талантами, символами, профессиями, титулами и наборами одежды.

## Требования

- Клиент World of Warcraft **3.3.5a**.
- Сервер **Sirus**. Аддон обращается к функциям, которых в обычном 3.3.5 нет: `C_Talent` для наборов талантов, серверные данные о комплектах предметов, очки усилений. На чистом WotLK-сервере часть вкладок работать не будет.

## Установка

1. Скачайте архив и распакуйте его в `Interface\AddOns` так, чтобы получился путь:

   ```
   World of Warcraft\Interface\AddOns\NarcissusSirus\NarcissusSirus.toc
   ```

2. Полностью перезапустите клиент. `/reload` не поможет: список файлов аддона читается только при запуске.
3. В игре наберите `/narci` или нажмите `C`.

## Что умеет

**Окно персонажа.** Модель, которую можно вращать мышью и приближать колесом. Слоты снаряжения расположены дугами по краям: уровень предмета, цвет качества, самоцветы, точка состояния чары и название предмета. Мир за окном затемняется, чтобы подписи читались на любой локации.

**Статы.** Полный список характеристик в две колонки. Приоритетные для вашего класса, специализации и надетого комплекта подсвечены зелёным — набор капов собран из гайдов по классам, а комплект определяется по серверной таблице предметов, а не по уровню вещей.

**Усиления.** Распределение и сброс очков усилений со стоимостью.

**Таланты и символы.** Все ветки в одном окне, переключение между наборами талантов, покупка второго набора, сброс. Вкладка символов показывает большие и малые гнёзда и позволяет вставлять и снимать символы.

**Профессии.** Список изученных профессий с уровнем навыка; щелчок по значку открывает окно ремесла. Окно ставится в свободную полосу между дугами снаряжения, чтобы не перекрывать слоты — это удобно при массовом наложении чар.

**Титулы** и **быстрые наборы** одежды с предпросмотром содержимого набора.

**Снаряжение.** Список надетого, сгруппированный по источнику: из какого рейда или подземелья вещь, есть ли на ней чара, остались ли пустые разъёмы, средний уровень предметов.

**Скриншоты** без интерфейса, сразу или с обратным отсчётом.

## Команды

| Команда | Что делает |
| --- | --- |
| `/narci` | открыть или закрыть окно персонажа |
| `/narci config` | настройки |
| `/narci scale` | показать масштаб окна; `/narci scale 0.8` закрепить, `/narci scale auto` вернуть автоподбор |
| `/narci dim` | затемнение игрового мира, `0`–`100` |
| `/narci prio` | что определено для подсветки характеристик; `/narci prio 5` закрепить комплект Т5, `/narci prio auto` вернуть автоопределение |
| `/narci outfit`, `/narci save <имя>`, `/narci load <имя>`, `/narci delete <имя>`, `/narci list` | наборы одежды |
| `/narci screenshot` | снимок без интерфейса |
| `/narci bags` | диагностика: какие сумки видит аддон и подняты ли они над окном |

## Настройки

Открываются через `/narci config`, правым щелчком по кнопке на миникарте или последней кнопкой в панели окна.

- Что показывать на слотах: уровень предметов, метки чар, самоцветы, названия предметов и их длину, скрывать ли пустые ячейки.
- Подсветка приоритетных характеристик.
- Скрывать ли штатный интерфейс, пока окно открыто.
- Затемнение мира, подсветка за моделью, анимации.
- Масштаб окна: подбирается автоматически под размер экрана либо задаётся вручную.
- Запоминать поворот и приближение модели между открытиями.
- Цвет темы, язык интерфейса, вкладка, открывающаяся вместе с окном.

Смена языка и цвета темы требует перезагрузки интерфейса: подписи и цвета копируются в элементы в момент их создания. Окно об этом предупреждает и перезагружает само.

## Язык

Русский и английский, по умолчанию — язык клиента. Переключается в настройках.

## Необязательная зависимость

Панель «Снаряжение» берёт данные об источниках предметов из аддона [InspectEquip](https://www.curseforge.com/wow/addons/inspectequip) — она читает его таблицу `InspectEquip_ItemSources`. Без него аддон работает, но все вещи попадут в группу «Неизвестно».

## Особенности, о которых стоит знать

- **Наложение чар** идёт в два шага: правый щелчок по свитку в сумке, затем левый по слоту. Автоматизировать это нельзя — движок игры требует настоящего щелчка мышью по защищённой кнопке, и «наложить всё разом» технически невозможно.
- Кнопки слотов защищённые, поэтому в бою окно не будет менять их размер и видимость; всё отложится до конца боя.
- Аддон прячет чужие окна, пока открыт, и возвращает их при закрытии. Если какой-то нужный вам фрейм пропадает — его имя нужно добавить в список исключений в `UI/NarciUI.lua`.
